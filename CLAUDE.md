## Project rules

@docs/mobile-portrait-rules.md

- **Header width:** the site header's inner row is always wider than the page content container, about
  `90vw` on large screens and a 10–16px edge on smaller ones (`w-header` utility in `globals.css`).
- **Branches:** this is a live client site. Commit and push straight to `main`; Vercel's production deploys
  from `main`. `claude/selah-lodges-nextjs-setup-1lq6aw` is a frozen backup only: never push to it. Template
  and demo work lives in the separate Stay-Sites repo, never here.
